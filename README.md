# KATA-008A: DataPipeline

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

## Como resolver

1. Abra `src/main/java/com/skillforge/kata/DataPipeline.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/DataPipelineTest.java`
3. Implemente até todos os testes passarem
4. Verifique: `mvn verify`

```bash
git checkout -b kata-008a-{heroId}-solution

git push origin kata-008a-{heroId}-solution
```
