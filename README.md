# KATA-001B: BlockingIoService

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

1. Abra `src/main/java/com/skillforge/kata/BlockingIoService.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/BlockingIoServiceTest.java`
3. Implemente até todos os testes passarem
