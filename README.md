# KATA-016E: TernaryOps

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

## Como resolver

1. Abra `src/main/java/com/skillforge/kata/TernaryOps.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/TernaryOpsTest.java`
3. Implemente até todos os testes passarem
4. Verifique: `mvn verify`

## Como submeter

```bash
git checkout -b kata-016e-{heroId}-solution
git commit -am "kata-016e: implement TernaryOps"
git push origin kata-016e-{heroId}-solution
# Abra PR com body: heroId: {heroId}
```
