# KATA-014A: TextProcessor

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

## Como resolver

1. Abra `src/main/java/com/skillforge/kata/TextProcessor.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/TextProcessorTest.java`
3. Implemente até todos os testes passarem
4. Verifique: `mvn verify`

```bash
git checkout -b kata-014a-{heroId}-solution
git commit -am "kata-014a: implement TextProcessor"
git push origin kata-014a-{heroId}-solution
```
