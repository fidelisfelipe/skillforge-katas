# KATA-016B: UnaryOps

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

## Como resolver

1. Abra `src/main/java/com/skillforge/kata/UnaryOps.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/UnaryOpsTest.java`
3. Implemente até todos os testes passarem
4. Verifique: `mvn verify`

```bash
git checkout -b kata-016b-{heroId}-solution
git commit -am "kata-016b: implement UnaryOps"
git push origin kata-016b-{heroId}-solution
# Abra PR com body: heroId: {heroId}
```
