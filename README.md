# FHIR-015: FhirMustSupportRules

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

## Como resolver

1. Abra `src/main/java/com/skillforge/kata/FhirMustSupportRules.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/FhirMustSupportRulesTest.java`
3. Implemente até todos os testes passarem
4. Verifique: `mvn verify`

## Como submeter

```bash
git checkout -b fhir-015-{heroId}-solution
git commit -am "fhir-015: implement FhirMustSupportRules"
git push origin fhir-015-{heroId}-solution
# Abra PR com body: heroId: {heroId}
```
