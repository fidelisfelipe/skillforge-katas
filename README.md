# KATA-014B: TextFormatter

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

1. Abra `src/main/java/com/skillforge/kata/TextFormatter.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/TextFormatterTest.java`
3. Implemente até todos os testes passarem
4. Verifique: `mvn verify`
