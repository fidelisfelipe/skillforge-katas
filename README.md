# KATA-016A: ArithmeticOps

> Consulte `quests/dojo/java-21-certified/catalog.yml` no repo `skillforge` para a spec completa.

## Como resolver

1. Abra `src/main/java/com/skillforge/kata/ArithmeticOps.java`
2. Leia os testes em `src/test/java/com/skillforge/kata/ArithmeticOpsTest.java`
3. Implemente até todos os testes passarem
4. Verifique: `mvn verify`
